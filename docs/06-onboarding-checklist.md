# 06. Account Onboarding Checklist

**Account / Asset:** ______________  **Date:** ________  **Onboarded by:** ________

## A. Pre-Onboarding
- [ ] Account found in discovery or requested via ticket (ID: ______)
- [ ] Business owner identified: ______
- [ ] Technical owner identified: ______
- [ ] Business justification documented
- [ ] Tier (0/1/2) and criticality assigned
- [ ] Shared/duplicate/stale account check done
- [ ] Dependencies identified (services, scheduled tasks, apps using this credential)

## B. Configuration
- [ ] Managed System created (name, platform, address, functional account)
- [ ] Managed Account created (username, type)
- [ ] Network connectivity to target verified (required ports open)
- [ ] Functional account has minimum rights to change passwords
- [ ] Rotation policy set (after use / schedule: ______)
- [ ] Password complexity policy applied
- [ ] Smart Rule/Group membership verified
- [ ] Access policy applied (P__)
- [ ] Approvers and requester groups mapped

## C. Validation
- [ ] Test connection successful
- [ ] Test password rotation successful
- [ ] Test access request and approval flow
- [ ] Test session launch and confirm recording
- [ ] Test check-in triggers rotation
- [ ] Dependent services verified after rotation

## D. Closure
- [ ] Owner notified and confirmed
- [ ] Old shared credential disabled/rotated
- [ ] Evidence attached (screenshots/export)
- [ ] Added to recertification calendar
